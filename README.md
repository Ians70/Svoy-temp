# Свой темп · MVP 0.1

Первый прототип тренажёра с гирей: подбор короткого комплекса с учётом времени суток, самочувствия и доступных минут; таймер; карточки упражнений; профиль и история занятий.

## Публикация на GitHub Pages

1. На GitHub создайте **отдельный публичный** репозиторий `svoy-temp`. Репозиторий `elections2026-il` не затрагивается.
2. Загрузите **в корень нового репозитория** содержимое этого архива: `index.html`, `sw.js`, `manifest.webmanifest`, оба PNG, `.nojekyll` и `README.md`. Важно: не помещайте их в дополнительную папку.
3. Откройте **Settings → Pages**; в **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем **Save**.
4. После публикации адрес будет `https://ians70.github.io/svoy-temp/`, если владелец репозитория `ians70` и название `svoy-temp`.
5. Откройте сайт в Chrome на Android. В меню браузера можно выбрать **Установить приложение** или **Добавить на главный экран** (точное название зависит от браузера и условий установки PWA).

### Проверка на телефоне

- Откройте приложение из браузера, измените длительность и самочувствие, запустите таймер.
- Создайте тестовую запись тренировки и убедитесь, что она появилась в истории.
- После успешной первой загрузки и установки включите авиарежим и попробуйте открыть приложение повторно.
- Если GitHub Pages недавно изменился, для получения новой версии понадобится хотя бы один онлайн-запуск.

### Известные ограничения MVP

- Логика подбора и недельного плана демонстрационная, не индивидуальное назначение физической нагрузки.
- Иллюстрации техники упражнений пока отсутствуют, подставлены заглушки.
- Приложение **не выполняет медицинскую оценку** ограничений и не определяет безопасный вес гири.
- Данные сохраняются в `localStorage` этого браузера; нет синхронизации или резервной копии.
- Функциональность в фоне и таймер на разных Android-устройствах не прошли полноценное E2E-тестирование.
- PWA-кэш ограничен собственным путём `/svoy-temp/`; ссылки на другие сайты потребуют интернета.
